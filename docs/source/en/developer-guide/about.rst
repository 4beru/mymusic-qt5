About MyMusic
=============

MyMusic is a maintained edition of the PyQt5 desktop player originally
developed as Groove Music. The upstream project began on May 1, 2020 as
a local music player and later added online music, synchronized lyrics
and music videos.

The project offers a practical example of desktop GUI development,
relational data access, image processing, design patterns and network
integrations.
