# Keyboard shortcuts

## Global media controls

Where supported by the platform, media keys can control playback even when MyMusic is not the focused window, including when minimized to the system tray.

| Key | Action |
| --- | --- |
| Play/Pause | Toggle playback |
| Previous track | Play the previous song |
| Next track | Play the next song |

## Application shortcuts

These shortcuts apply while the application has focus.

| Shortcut | Action |
| --- | --- |
| Right arrow | Seek forward |
| Left arrow | Seek backward |
| Escape | Exit full-screen mode |
| Space | Toggle playback |
| Ctrl + Plus | Increase playback speed |
| Ctrl + Minus | Decrease playback speed |
| Ctrl + Enter | Restore the default playback speed |
